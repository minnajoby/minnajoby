## 🚀 Projects

### 🏦 [RetentionAI — Bank Customer Churn Prediction System](https://github.com/minnajoby/RetentionAI)
> Predicting customer churn using advanced ML models on 165K+ records.

- Built a full ML pipeline with **CatBoost, LightGBM, TabNet, and TabPFN**
- Applied **SMOTE-Tomek** resampling to handle class imbalance
- Used **SHAP** for model explainability and churn driver analysis
- Deployed via a **Flask** web app for real-time churn risk prediction

---

### 🎯 [PrepScore — AI-Powered Career Readiness Analyzer](https://github.com/minnajoby/PrepScore)
> A full-stack platform that analyzes user profiles for job compatibility.

- Built with **Django** and **PostgreSQL (pgvector)** for vector-based semantic search
- Implemented a hybrid scoring model combining **Random Forest** + **NLP embeddings**
- Developed resume parsing and skill gap analysis using vector similarity
- Designed an analytics dashboard with **Chart.js** and **Bootstrap**
